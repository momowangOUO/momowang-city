# 魔魔王 Logo 应用规范

状态：应用研究，未批准用于正式生产。原稿与正式资产审批仍以 `spec/signature.yaml` 为准。

## 1. 基础定义

识别核心是三字“左紧、中承、右放”的走势、两个魔字的向外双角、王字上方的不规则小王冠、粗重墨块与扫出的收尾。外轮廓、关键负形及字间关系优先于颜色和材质。不得用字体重排，不得将角改成耳朵、翅膀或火焰，不得换成图库王冠。

用户提供的完整规则保存在 [APPLICATION_SOURCE.md](APPLICATION_SOURCE.md)。首页范例目录使用 `gallery/public/examples/catalog.json`，每组记录原规则章节、展示内容和验收要求。AI 范例只表达应用方向，不是矢量母版、生产文件或尺寸验收依据。

## 2. 标准版本与授权边界

| 版本 | 做法 | 正式使用前检查 |
| --- | --- | --- |
| 主黑版 | 浅底纯黑；保留原有轮廓与镂空 | 与批准母版逐项比较 |
| 反白版 | 深底纯白；负形透出背景 | 检查暗底上的细缝与视觉重量 |
| 单色版 | 整体使用一种颜色，背景保持反差 | 颜色作为独立用途记录并审阅 |
| 无装饰版 | 仅移除经批准的外围星点，保留主体、角、冠 | 建立独立候选，不覆盖完整版 |
| 小尺寸版 | 按实际显示尺寸减少细节、扩大必要间隙 | 每种尺寸与颜色分别实测 |
| 图标版 | 研究王冠＋王、角＋魔、单冠、极简墨块 | 属于新衍生版本，须独立批准 |
| 轮廓版 | 用于发光、雕刻等辅助场景 | 检查轮廓闭合、线宽与小间隙 |
| 水印版 | 低透明度、低干扰，保留结构 | 在实际底图检查辨识与内容遮挡 |
| 印章／贴纸版 | 底板、框与签名分层，保留安全区 | 检查裁切边、出血与背景反差 |

本次授权用于制作上述应用范例。正式 CLI 目前仍只输出已有审批流程支持的黑白版本；彩色、描边、简化、倾斜、图标及工艺效果不能因范例存在而自动进入正式导出。添加这类生产能力时，先建立候选和用途规则，再审阅批准。

## 3. 颜色与背景

- 黑白是基准。扩展色包括深灰、浅灰、品牌色、专色与单一金属色模拟。红／米、金／黑、银灰／深蓝、深紫／浅灰、荧光绿／黑、奶油白／墨绿是候选搭配。
- 浅底选深标、深底选浅标。照片与动态背景不能仅凭平均亮度自动反色：检查签名覆盖区域，必要时使用固定底板、半透明底板、局部模糊带或克制描边。
- 实心、反白与真正镂空是不同做法。镂空依赖下层材质或灯光，实体切割需检查孤岛与连接桥；不能把反白图片当作切割文件。
- 轮廓和填充加描边用于辅助场景。描边不能堵住内部负形或淹没尖角。渐变优先放在背景，避免把主体切成多段色块。
- 纸、混凝土、金属、皮革、磨砂亚克力、布料、喷漆墙和撕贴海报均需检查局部反差。纹理不得吞掉轮廓。
- 外发光、背发光、投影和半透明叠加均应保留清晰的主体边缘。金属高光、厚阴影、液化与火焰不得替代形状识别。

## 4. 尺寸与内容层级

| 场景 | 选择 | 检查方法 |
| --- | --- | --- |
| 大：墙面、舞台、海报、片头 | 完整版 | 远观走势、尖角与安全区 |
| 中：名片、包装、封面、贴纸 | 完整或经批准的减装饰版 | 按实际物理／像素尺寸检查 |
| 小：头像、App、角标 | 独立简化版 | 检查双角、冠与关键间隙，不硬塞星点 |
| 极小：favicon、按钮 | 独立图标候选 | 不强行缩小三字完整版 |

规范中的最小屏幕宽度和最小印刷宽度仍待实际测试；不得从 AI 图里推断数值。内容层级为完整、减装饰、核心三字、印章底框、重复纹样。纹样可用斜向／疏排／错位排列，但每个单元保持批准形状。

## 5. 工艺做法

| 工艺 | 对应做法 | 交付前要求 |
| --- | --- | --- |
| 平面印刷 | 单黑、反白、专色；丝网、数码、UV 分开打样 | 明确色彩空间、介质、出血与专色；AI 图不是印刷稿 |
| 压凸／压凹 | 同色纸面、皮革、封面以光影显示 | 供应商确认深度、最细线／缝、纸厚与套准 |
| 烫箔 | 亮金、哑金、玫瑰金、银、黑金、镭射、彩箔 | 独立箔版与材质实样；显示器渐变不代表箔色 |
| 金属 | 蚀刻、激光、CNC、冲压徽章 | 供应商确认刀径、桥位、深度、边缘与安全性 |
| 刺绣 | 单色、撞色、毛巾绣、平绣／绣章 | 独立简化候选与针法文件，绣样验证，不直接转 AI 图 |
| 胶章 | PVC、硅胶、橡胶浮雕 | 分层与模具稿，确认间隙、厚度和脱模条件 |
| 发光 | 霓虹轮廓、实心背光、白／暖／红／紫／RGB | 明确灯路与背板，检查过曝是否吞边 |
| 模板／投影 | 漏版、切割板、gobo、舞台投影 | 检查连接桥、最小孔洞与实际投射距离 |

## 6. 数字应用与组合

头像采用方形或圆形安全区，角与冠不得贴边；横幅可左标右角色、居中或使用背景水印。UI 图标须使用独立批准版本。水印可角落、重复或居中大幅低透明度，按实际作品检查干扰。

布局支持居中、顶部角落、底部署名、大背景衬底。顺势倾斜只用于明确批准的应用版本，禁止倒置、镜像与强行竖排。与角色并置时选留白区域；与标题组合时保持分层和间距；墨团、胶带、徽章框不能侵入关键轮廓。

动效范例为分镜：书写、墨块显现、描边转实心、双角→主体→冠、反色切换／闪现、盖章、扫出、星点最后出现。真正制作动画时使用批准图层／遮罩，末帧应与母版一致，避免融化与过量粒子。本次不将静态分镜称作已实现的动画。

## 7. 特殊风格

风格研究包括笔刷、干净平面、喷漆、印章、金属徽章、夜光／荧光、磨砂玻璃。它们是材质或表面处理，不能借风格名义重写字形。“干净平面”范例仍是位图，不能称为矢量文件。

不使用拉伸、压扁、局部挤压、低对比、特效吞边、任意替换王冠和双角或小尺寸细节挤成团的素材。确认失败的素材及展示内容直接删除，不设错误案例入口。

## 8. 从范例到交付

1. 在首页选范例，记录用途、背景、颜色、实际尺寸、介质和工艺。
2. 读取固定版本和真实资产；缺失或校验不通过就停止，不生成替代签名。
3. 仅做已批准的等比缩放与放置；新颜色、轮廓、简化或工艺分层作为独立候选审阅。
4. AI 主视觉先生成背景；正式合成使用真实批准资产。AI 场景样机只帮助选方向。
5. 检查轮廓、关键负形、双角、冠、背景反差、安全区、实际尺寸；实体工艺追加供应商打样。
6. 所有者批准后，固定版本导出并验证消费项目锁文件。不得更新真实视觉基准或降低阈值来迁就范例。

每次修改运行 `npm run check`，首页修改追加 `npm run build` 和浏览器验证。原稿只保存在已确认的私人仓库；上传和正式发布遵循项目授权。
