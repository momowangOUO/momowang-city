# Logo 呈现方式系统 / Shape Mask

依据 [用户原文](PRESENTATION_SOURCE.md)。本文件规定研究方案与实现参数，不代表正式资产批准。轮廓、双角、王冠、主体比例、内部负形不变；原稿保留完整字节。

## 选择顺序与 C1—C5

| 等级 | 名称 | 处理与用途 | 退回条件 |
| --- | --- | --- | --- |
| C1 | Solid Contrast | 首选纯黑／纯白或批准单色 | 跨越复杂明暗导致局部消失 |
| C2 | Desaturated Mask | 去色 80%—100%，亮度偏移 15%—30%，对比 1.10—1.25 | 原背景接近灰度，处理差异不足 |
| C3 | Luminance Inversion | 只反转线性光亮度，尽量保留色彩方向 | 中灰区域差异小或大面积碎裂 |
| C4 | Difference | 差值混合，适合数字艺术和动态视觉 | 内容变化导致轮廓分裂 |
| C5 | Frosted Mark | 轻度模糊、去色、适度明暗偏移 | 模糊使内部纹理丢失，或背景本就模糊 |

先尝试 C1，再考虑 C2／C3；C4 由表现需求选择，C5 由 UI／柔焦需求选择。RGB 负片、色相、双色、二值化是特殊版本，不按等级高低默认升级。上述等级是命名，不是已批准状态。

## 共同合成规则

令背景为 B，正形覆盖率为 M，处理为 F。严格蒙版输出为 `B × (1-M) + F(B) × M`。背景、人物、纹理仍来自同一个像素位置，不填一张无关图。M=0 的外部与内部孔洞保留原 RGBA 字节；完整版本的角、冠、星点全部使用同一处理。

当前 PNG 的临时蒙版来源和白底阈值见 [城市设计记录](CITY_DESIGN.md)。这是栅格研究，不是自动批准的矢量母版。采样背景与效果必须同尺寸、同坐标；先处理完整背景，再按蒙版合成，避免模糊采到透明黑边。

## 31 条需求的对应做法

| 原文 | 设计做法／实验台实现 |
| --- | --- |
| 1 标准单色 | 黑、白、品牌红；专色和金属模拟沿用单色范例板。实色为 C1，不标成蒙版 |
| 2 自动反差 | 按蒙版覆盖的背景平均线性亮度比较黑／白对比，选择整体更高者；平均值不能保证所有局部清晰 |
| 3 Shape Mask | 正形处理，外部与孔洞不动；支持原图对照 |
| 4 降饱和 | 轻度 50%、标准 80%、完全去色；灰底可能失效 |
| 5 去色＋明度 | 默认去色 90%，对比 1.18，暗底加 0.20、亮底减 0.20 的归一化通道偏移；滑杆控制合成强度 |
| 6 明度反相 | sRGB 转线性 RGB，Y=0.2126R+0.7152G+0.0722B，Y′=1-Y；沿原色彩差向量恢复，必要时压缩色度以避免溢出，然后转回 sRGB |
| 7 RGB 负片 | 各 sRGB 通道 `255-channel`，只作用于正形 |
| 8 Difference | 归一化 `abs(B-S)`；默认 S=1，因此与 RGB 负片相同，区别在混合机制而非伪造两种结果 |
| 9 Exclusion | `B+S-2BS`；用 S=0.72 展示柔和版本。S=1 时与白色 Difference 完全相同，不宣称天然更柔和 |
| 10 局部反差 | 对背景做大范围模糊后取得亮度，平滑决定正形内提亮／压暗；不用原始逐像素黑白开关 |
| 11 暗玻璃 | 黑叠加 40%，饱和度保留 65%，轻微模糊 |
| 12 白玻璃 | 白叠加 40%，饱和度保留 65%，轻微模糊 |
| 13 磨砂 | 模糊标准差约 Logo 本体高度 2%，去色 80%，对比 0.85，自动明暗偏移 |
| 14 低对比 | 通道围绕 0.5 缩到 55%，保留明暗内容 |
| 15 单色染色 | 原背景明暗映射为魔红、魔紫、王金、夜蓝、墨绿色阶；不是纯色填充 |
| 16 色相偏移 | HSL 中 H 增加 60°／90°／180°，S/L 保留；不是 RGB 负片，也不宣称严格保留感知亮度 |
| 17 高对比黑白 | 去色，对比 1.8，保留连续中间灰阶 |
| 18 二值化 | 去色后以 0.5 为阈值只保留 0／1；边缘覆盖率仍抗锯齿 |
| 19 Posterize | 亮度量化为 2／3／4 级，再映射黑红／紫白／黑金，不冒充精确印刷分色 |
| 20 双色 | 以原背景亮度在两端色之间连续映射；黑红、黑白、黑金、黑紫、深蓝白；区别于两级阈值 |
| 21 模糊 | 轻度 1%、中度 2% 本体高度；去色／提亮／压暗组合 |
| 22 模糊＋去色 | 轻模糊＋去色 90%＋对比 0.9＋自适应明暗 |
| 23 实色边缘保护 | 细边只用于辅助分离；受当前未批准母版限制，只展示研究，不修改正式导出 |
| 24 蒙版边缘保护 | 1—2px 或本体宽 0.1%—0.3%，独立标明保护层影响范围 |
| 25 Halo | 处理正形周围少量背景，明确是“外围辅助”，不归入外部不变的严格蒙版；不可误作霓虹外发光 |
| 26 负形 | 空洞、字间、冠下与角下空间均回到原背景；测试零覆盖像素不变 |
| 27 装饰 | 完整版所有正形共用处理；不把王冠随意填黑、星点填白 |
| 28 简化 | 仅建立待审方向，先减小点、飞溅、次星、细线；保留三字双角王冠；本实验台不自动删除像素 |
| 29 等级 | 上述 C1—C5 五级目录与参数 |
| 30 优先级 | 先清晰再表现；失效时改位置、背景或已批准版本，不盲目加特效 |
| 31 核心原则 | 颜色与材质可变，形状仍是品牌本体 |

## 验收

先对照原稿形状，再检查差异：外部零变动、孔洞零变动、整体等比、双角和冠完整、星点同处理、轮廓连续。检查亮底、暗底、灰底与跨明暗背景；不只检查一张好看的图。记录处理参数、源文件哈希、背景、输出尺寸和 CONCEPT_ONLY 状态。实际使用需独立审阅；灰底 Difference、低饱和底去色与高频背景碎裂均不能自动判为通过。
