# 午夜街区 · 城市探索交付

2026-10-01。入口：[GitHub Pages 网站](https://momowangouo.github.io/momowang-city/)。源码及制作源图保持私人；公开仓库只接收静态构建和已授权素材。

## 实现

六个连续街区：高架入口、霓虹侧街、深夜印刷铺、改装店、玻璃廊、地下灯场。原生滚动驱动镜头、人物步相和建筑遮挡转场；没有滚轮劫持、声音或强制片头。路线索引支持搜索，物件可直接点击，也可通过“附近物件”与键盘进入。

画法保留日系赛璐璐和粗黑轮廓，场景为赛博朋克城市。人物以六头身比例源图为基准，黑色 X 发夹、黑衣、冷淡半垂眼神；站姿和坐姿分别拆出头发、双臂、双腿、衣摆与绑带。起身、前行、返回使用完整透明动作帧及共同脚底线，未镜像或拉长肢体。

首屏有十二座独立楼体、分速云层、完整列车、三款分件无人机、窗灯、风扇、微粒、天空原稿 Logo 与 24 秒大屏循环。其余街区保留独立电缆、灯具、蒸汽、地面反光、人物及发光物件。手机保留三架无人机、较少微粒和较低大屏分辨率。

追视只在首屏前 70% 视口距离内工作，眼部原绘虹膜仅移动 2.3×0.8 个源像素，约 300ms 回正；没有另画小眼珠。触屏、暂停、减少动态、离屏和后台均停止相应更新。较远街区的表面 Canvas 在切换时释放。

## Logo 与物件

28 组、161 项入口映射到门、店牌、纸张、包装、绣章、机器人及玻璃等实际载体。近景单独策展：材质图保留正面、厚度和投影；蒙版采用明亮彩色玻璃或清晰条纹玻璃，以显示去色、色相和模糊差异。字形始终取自原始 PNG。

最佳呈现保留头像、水印、重复纹样、标题组合和角落摆放；同底对照固定照片、裁切、位置、尺寸和四角投影。八种 Logo 显现使用独立循环，暂停和减少动态状态显示完整形状；下载为完整静态合成帧。

严格 Shape Mask 的外部及孔洞保留原像素。边缘辅助、Halo、材质厚度与排版装饰是明确的独立呈现，不冒充严格蒙版。轮廓版按表面宽度的 0.5% 计算内侧线宽，600/1200px 渲染的归一化墨量差约 1.2%，避免手机缩小后断线；其他效果不额外加描边。

## 清晰度与适配

- 六区均有独立竖屏构图。检查 1440×900、1920×1080、2560×1440、375×812、390×844、430×932，无横向溢出。
- 城市底图最高按原生尺寸显示；超大视口使用前景建筑框景，不把小图放大或模糊来填边。物件近景也限制在其原生宽度内。
- 档案展示限宽 1440px，并按实际显示尺寸及最多 2 倍像素密度重绘。关闭档案时不预绘其大图。字体采用与本地原字体逐字轮廓相等的 167 字子集，106,340 字节，保留 OFL 许可。
- 本机 Chromium 测量：桌面 56.4fps，390×844、DPR 2 触屏模拟 56.8fps；5.5 秒样本的 P95 帧间隔约 18.1ms，均无超过 50ms 的帧。开发服务器冷加载约 6.76MiB / 4.52MiB，包含 Vite 开发模块；不作为真机性能保证。

## 验证

- `npm run check`：类型检查、27 项测试通过；工具配置 VALID。真实生产资产仍为 NOT_READY，没有母版或用途审批。
- `npm run build`：Vite 相对路径构建通过。
- `city-journey.verify.cjs`：六区桌面/手机、28 组入口、161 项数量、近景、下载、同底几何、暂停、追视截止与恢复。
- `city-variants.verify.cjs`：161 项逐项渲染与导出链接，近景无底图放大；实际截图逐组检查。
- `world-surface.verify.cjs`、`surface-projection.verify.cjs`：原图精确复制、严格蒙版外部/孔洞、正面轮廓、透明 RGBA 合成与退化四角处理；相关不应改变像素的计数均为零。
- `applications.verify.cjs`、`gallery.verify.cjs`：档案筛选、46 个蒙版控件、零强度复原、下载、复制命令、本地背景、越界拦截与未批准状态。
- `city-controls.verify.cjs`：键盘搜索、原生模态、焦点恢复、真实下载、原图链接、八种显现动画和离屏暂停。
- `transit.verify.cjs`：列车源图四边有透明余量；在 1440、2560、375、390px 视口中，列车与无人机完全出画后才重置。
- `resolution.verify.cjs`：档案画布没有上采样，手机 DPR 2 足够；所有推荐旧载体的源宽至少 1440px。
- `pages.verify.cjs`：在 `/momowang-city/` 下检查 37 个实际链接，无 404 或页面异常。

浏览器脚本使用 Playwright CLI，例如：`playwright-cli -s=journey run-code --filename tests/city-controls.verify.cjs`。开发测试默认 5179；Pages 测试默认 5175 子路径。运行时先启动对应服务，完成后关闭会话。
